# Smart Listing Classifier

NLP-проект для автоматической классификации текстовых объявлений по категориям.

## О проекте

Smart Listing Classifier определяет категорию объявления на основе его заголовка и описания.

Проект создан как учебный NLP-кейс с задачей, близкой к классификации объявлений на маркетплейсах и классифайдах.

Модель должна определить одну из шести категорий:

- Электроника
- Мебель
- Автомобили
- Одежда
- Недвижимость
- Услуги

> Важно: в проекте используется синтетический учебный датасет, созданный специально для экспериментов. Он не содержит реальных данных Avito и не отражает production-систему Avito.

---

## Цель

Исследовать, как разные способы представления текста влияют на качество классификации объявлений.

В проекте последовательно сравниваются:

1. TF-IDF
2. TF-IDF с биграммами
3. Character-level TF-IDF
4. Transformer embeddings на основе RuBERT

---

## Датасет

Используется синтетический датасет из 420 объявлений.

Каждая запись содержит:

- `title` — заголовок объявления;
- `description` — описание;
- `category` — целевая категория;
- `text` — объединённый текст заголовка и описания.

Датасет сбалансирован:

| Категория | Количество |
|---|---:|
| Электроника | 70 |
| Мебель | 70 |
| Автомобили | 70 |
| Одежда | 70 |
| Недвижимость | 70 |
| Услуги | 70 |
| **Всего** | **420** |

Данные разделены на:

- 80% обучающей выборки;
- 20% тестовой выборки.

Разделение выполняется стратифицированно, чтобы сохранить одинаковое распределение категорий.

В проекте используются две версии синтетического учебного датасета:

- `smart_listing_dataset.csv` — Dataset v1, 360 объявлений;
- `smart_listing_dataset_v2.csv` — Dataset v2, 420 объявлений.

Обе версии содержат 6 категорий объявлений:

- Электроника
- Мебель
- Автомобили
- Одежда
- Недвижимость
- Услуги

Dataset v2 был создан после анализа ошибок первой версии и содержит дополнительные примеры для повышения разнообразия формулировок.

> Данные являются синтетическими и используются исключительно в образовательных и портфолио-целях. 


## Эксперименты

### 1. TF-IDF + Logistic Regression

Первый эксперимент использует классическое представление текста TF-IDF.

Результат на Dataset v1:

**Accuracy: 1.000**

Однако дальнейшее ручное тестирование выявило проблемы с некоторыми формулировками.

---

### 2. TF-IDF + биграммы

В следующем эксперименте были добавлены униграммы и биграммы:

```text
ngram_range=(1, 2)

Это позволило учитывать не только отдельные слова, но и короткие словосочетания.
Результат:
Accuracy: 1.000

---

### 3. Расширение датасета

После анализа ошибок Dataset v1 был расширен.

Количество объектов увеличилось:
360 → 420

При этом появились дополнительные варианты формулировок внутри каждой категории.

На Dataset v2 TF-IDF + Logistic Regression показал:
Accuracy: 0.988

Интересно, что снижение Accuracy сопровождалось улучшением поведения модели на некоторых новых примерах.

Например:
Кожаный диван в хорошем состоянии, возможен торг

На первоначальном варианте модели объявление ошибочно классифицировалось как Автомобили.

После расширения датасета модель определила его как:
Мебель
---
### 4. Error Analysis
Отдельно анализировались ошибки модели.

Один из примеров:
Пуховик. Зимний пуховик, почти не носили

TF-IDF-модель определила его как:
Недвижимость

Анализ словаря показал, что слова:
пуховик
зимний
носили
отсутствовали в словаре модели.

Фактически значимым активным признаком оказалось слово не.

Этот пример показал ограничение word-level TF-IDF при работе с небольшим датасетом и ранее не встречавшимися словами.

---

### 5. Character TF-IDF
Для проверки альтернативного подхода был использован character-level TF-IDF:
analyzer="char"
ngram_range=(3, 5)

Количество признаков:
9873

Результат:
Accuracy: 0.976

Таким образом, увеличение количества признаков само по себе не привело к улучшению качества.
---

### 6. RuBERT embeddings

Финальный эксперимент использует:
cointegrated/rubert-tiny2

RuBERT используется для получения контекстных представлений текста.

Полученные embeddings передаются в Logistic Regression.

Размер embedding:
312 признаков

Результат:
Accuracy: 1.000

Сравнение моделей
Модель	                                 Датасет	   Признаки	  Accuracy
TF-IDF + Logistic Regression             Dataset v1	   364	          1.000
TF-IDF + биграммы + Logistic Regression	 Dataset v1	   1127	          1.000
TF-IDF + Logistic Regression	         Dataset v2	   480	          0.988
Character TF-IDF + Logistic Regression	 Dataset v2	   9873	          0.976
RuBERT embeddings + Logistic Regression	 Dataset v2	   312	          1.000

Robustness Test

Помимо стандартного train/test split, модель была проверена на вручную составленных объявлениях с менее очевидными ключевыми словами.

Например:
Продам удобный предмет для дома, мягкий и большой

Предсказание:
Мебель

Уверенность:
0.775

Другой пример:
Устройство для работы и учёбы, хорошее состояние

Предсказание:
Электроника

Уверенность:
0.759

Модель правильно определяла категории, однако на менее информативных текстах её уверенность снижалась.

Это показывает, что правильное предсказание не всегда означает высокую уверенность модели.

Inference
В проекте реализована функция predict_listing(), которая принимает текст нового объявления и возвращает:
предсказанную категорию;
вероятность каждой категории.

Пример:
text = """
Продаю ноутбук Lenovo IdeaPad.
16 ГБ оперативной памяти, SSD 512 ГБ.
Подходит для работы и учёбы.
"""

prediction, probabilities = predict_listing(text)

print(prediction)
print(probabilities)

Ограничения

Результаты проекта нельзя напрямую переносить на реальные объявления.

Основные ограничения:
небольшой размер датасета;
синтетические данные;
регулярность некоторых формулировок;
отсутствие реальных пользовательских объявлений;
отсутствие production-like validation set;
высокая вероятность того, что тестовая выборка проще реальных данных.

Поэтому Accuracy = 1.000 следует рассматривать как результат эксперимента на данном учебном датасете, а не как оценку качества production-модели.
